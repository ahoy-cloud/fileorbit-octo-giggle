# FileOrbit

FileOrbit 是一个 macOS 本地文件整理原型：在 Finder 拖动文件时按住 Shift，打开一个小转盘，选择目标文件夹后松手即可整理。

## 功能

- 自定义首层目标文件夹，也可从设置窗口新建文件夹。
- 在文件夹扇区停留约半秒，进入其子文件夹；中心可放入当前文件夹，外圈可返回。
- 在“移动”和“复制”模式之间切换。重名文件会自动加序号。
- “废纸篓”扇区会先请求确认，再移入系统废纸篓。
- 从菜单栏撤销本次运行期间最近一次整理；左键菜单栏图标打开设置。
- 自定义转盘颜色，并可调整设置窗口大小。

## 环境与构建

需要 macOS 13 或更新版本，以及 Xcode Command Line Tools。项目当前运行版使用 Objective-C 和 macOS 系统框架，无第三方包依赖。

```bash
zsh build-app.sh
open dist/FileOrbit.app
```

构建结果在 `dist/FileOrbit.app`。脚本会进行本地临时签名，方便开发测试；它不是经过 Apple Developer ID 签名和公证的正式分发包。

## 使用

1. 在设置窗口添加或新建目标文件夹。
2. 在 Finder 开始拖动文件，同时按住 Shift。
3. 将文件指向转盘扇区并松手；若想进入子文件夹，在扇区停留约半秒。
4. 右键菜单栏图标可切换整理模式或撤销最近一次整理。

首次尝试建议先用测试文件。移动、复制和废纸篓操作会更改文件位置；撤销仅保留最近一次记录，不跨应用重启。

## 隐私

FileOrbit 在本机保存你添加的目标文件夹路径和颜色设置；源码没有网络上传逻辑。仓库不包含用户设置、个人文件、截图或构建产物。
